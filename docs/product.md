# Hotspot — 제품 기획 요약

원본: 노션 「Hotspot — 웹 서비스 기획 발표」 (https://jk6841.notion.site/Hotspot-3ea31766f55f819fb749edcdaaf7342d).
기획이 바뀌면 노션이 기준이고, 이 문서는 구현 시 참고하기 위한 요약본이다.

**한 줄 소개**: 좋아하는 장소를 모으고, 친구와 나누는 서비스. 웹 우선, 데스크톱/모바일 반응형.

## 핵심 가치

1. **수집** — 지도에서 찾은 장소를 테마별 컬렉션에 저장
2. **관리** — 공개/비공개를 명확히 구분
3. **공유** — 팔로우한 친구의 활동을 타임라인(피드)으로 확인

## 도메인 개념

- **컬렉션**: 장소를 모아두는 단위. 공개/비공개 상태를 가진다. 공개로 전환하면 팔로워 피드에 노출된다.
- **장소**: 지도 provider에서 검색한 결과를 컬렉션에 저장한 것.
- **피드 활동**: 팔로우한 유저의 장소 추가/제외, 컬렉션 공개 등.
- **팔로우**: 유저 간 관계. 이름/핸들로 유저 검색.

## 화면 6종

| # | 화면 | 핵심 기능 |
|---|------|-----------|
| 01 | 로그인 | Google 소셜 로그인 (회원가입 절차 없음, 버튼 하나) |
| 02 | 피드 | 팔로우한 유저의 활동 카드 타임라인 (프로필 · 누가 무엇을 했는지 · 장소/컬렉션명 · 상대 시간) |
| 03 | 장소 찾기 | 현재 위치 중심 지도 + 검색(장소명/지역), 검색창 아래 최근 검색어, 지도를 눌러 그 주변 장소 찾기, 지도 아래 장소 리스트(이름 · 주소) |
| 04 | 컬렉션 | 컬렉션 카드(이름 · 공개/비공개 배지 · 장소 개수), 「+ 새 컬렉션」 |
| 05 | 컬렉션 상세 | 지도 + 장소 리스트, 공개 토글, 「+ 장소 추가」, 항목별 ✕ 제외 |
| 06 | 팔로워 | 팔로우 관계 목록(프로필 · 이름 · 핸들), 프로필 이동 |

사용자 흐름: 로그인 → 피드 → 장소 찾기 →(장소 저장)→ 컬렉션 → 컬렉션 상세 →(공개 전환)→ 팔로워 피드에 노출.

## 반응형

| 구분 | 데스크톱 | 모바일 |
|------|----------|--------|
| 내비게이션 | 상단 바 + 좌측 사이드바 고정 | 사이드바 → 햄버거 + 드로어 |
| 콘텐츠 | 사이드바 접기/펼치기 | 전체 폭 |
| 공통 | 상단 바와 검색 유지 | 상단 바와 검색 유지 |

## 디자인 가이드 (요약)

- 브랜드 컬러: 레드 포인트 (로고 · 활성 메뉴 · 지도 핀 · 주요 버튼)
- 밝은 뉴트럴 배경 위 둥근 카드
- 상태: 공개 = 보라 배지, 비공개 = 회색 배지
- 내비 메뉴: 장소 찾기 · 컬렉션 · 피드 · 팔로워 · 로그아웃
- 상세 토큰/컴포넌트는 루트 `DESIGN.md` 참고.

## 아직 구현되지 않은 것 (현재 코드 상태)

구현됨: 지도 provider 추상화(Kakao 장소 검색 API), Google 로그인(`docs/auth.md`), 컬렉션 목록 · 생성 · 수정(이름 변경 · 공개 전환) · 삭제(컬렉션 카드의 수정 버튼 → 수정 다이얼로그), 장소 찾기에서 컬렉션에 장소 담기 · 제외(선택한 장소 카드의 「컬렉션에 담기」 → 컬렉션 체크리스트), 장소 찾기의 최근 검색어(빈 검색창에 포커스하면 최신순 최대 10개 · 눌러서 다시 검색 · 개별/전체 삭제, 서버 저장), 지도를 눌러 그 주변 장소 찾기(가장 가까운 장소의 카드가 바로 열린다. Kakao 카테고리 그룹에 속하지 않는 장소는 나오지 않아 검색으로 찾아야 한다), 컬렉션 상세(컬렉션 카드의 이름 → 지도 + 장소 리스트, 항목별 ✕ 제외), 팔로우/언팔로우 · 팔로워 화면 · 유저 검색(`docs/database.md`).

미구현: 컬렉션 상세의 공개 토글 · 「+ 장소 추가」(공개 전환은 컬렉션 카드의 수정 다이얼로그에서, 장소 추가는 장소 찾기에서 한다), 피드 API 및 화면, 팔로워 화면의 프로필 이동(다른 유저의 프로필 · 공개 컬렉션 열람).
