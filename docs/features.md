# 기능 정리

## 서비스 개요

좋아하는 장소를 관리하고 사람들과 공유하는 서비스

## 핵심 엔티티

- **User**: 서비스 사용자
- **Place**: 지도상의 장소 (현재 지도 provider의 검색 결과 기반)
- **Collection**: 유저가 좋아하는 장소들을 묶어놓은 단위. 유저 1명이 N개 소유
- **Follow**: 유저 간 단방향 팔로우 관계

## 핵심 기능

### 1. 장소 컬렉션 저장
- 설명: 유저가 좋아하는 장소를 컬렉션 단위로 저장한다.
- 우선순위: MVP
- 상태: 계획

### 2. 컬렉션 다중 소유
- 설명: 유저 한 명이 여러 개의 컬렉션을 소유할 수 있다 (예: "서울 카페", "혼자 가기 좋은 곳" 등 주제별 분리).
- 우선순위: MVP
- 상태: 구현됨 (목록 · 생성. 이름 변경/삭제는 미구현)

### 3. 컬렉션 공개/비공개 설정
- 설명: 각 컬렉션마다 공개(다른 유저가 조회 가능) / 비공개(본인만 조회 가능) 여부를 설정할 수 있다. 공개 단계는 공개/비공개 2단계만 있고, "팔로워 공개" 같은 중간 단계는 없다.
- 우선순위: MVP
- 상태: 계획
- 비공개 → 공개 전환 시, 이미 저장돼 있던 장소들도 함께 공개된다. (컬렉션 단위로 공개 여부가 정해지고, 장소별 개별 공개 설정은 없음)

### 4. 유저 간 팔로우
- 설명: 유저는 다른 유저를 즉시(승인 없이) 팔로우할 수 있다. 팔로우의 목적은 (a) 상대방의 공개 컬렉션 열람, (b) 피드 구독 두 가지다.
- 우선순위: MVP
- 상태: 계획
- 팔로워 목록 공개 범위: followee(팔로우 받는 사람)는 자신의 follower 목록을 볼 수 있다. 제3자는 다른 유저의 follower 목록을 조회할 수 없다.

### 5. 피드
- 설명: 내가 팔로우한 유저들의 활동(예: 공개 컬렉션에 장소 추가/신규 공개 컬렉션 생성 등)을 모아 보여준다.
- 우선순위: MVP
- 상태: 계획
- 피드 이벤트 종류: 장소 추가, 장소 제외, 컬렉션 추가, 컬렉션 제외
- 비공개 컬렉션에 대한 활동(위 4종 이벤트 전부)은 피드에 노출되지 않는다.
